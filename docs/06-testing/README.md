# 06 - Pruebas y Calidad (Testing)

> Estrategia de pruebas unitarias, de integración y validación de modelos.

- **Frontend & Web:** Pruebas unitarias de componentes con Vitest / Bun Test.
- **ML Service:** Pruebas unitarias con `pytest` para validación de pipelines de datos y transformaciones.
- **Validación de Modelos:** Métricas de clasificación (Precision, Recall, F1-Score, ROC-AUC) sobre dataset de prueba estratificado.
